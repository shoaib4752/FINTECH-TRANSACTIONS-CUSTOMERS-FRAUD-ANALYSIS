# FINTECH-TRANSACTIONS-CUSTOMERS-FRAUD-ANALYSIS
Built an end-to-end FinTech Data Analysis project using Python, Pandas, SQL, PostgreSQL and Power BI. Analyzed 200K+ transactions from 2023–2025, covering customers, payments, merchants, fees, refunds, risk and fraud. Performed 30 SQL analyses and created a 4-page interactive Power BI dashboard with KPIs, trends and business insights.

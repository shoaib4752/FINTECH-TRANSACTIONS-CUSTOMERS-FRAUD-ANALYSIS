# FinTech Data Analysis Project

## 📌 Project Overview

This project is an end-to-end FinTech Data Analysis project built using Python, Pandas, PostgreSQL, SQL and Power BI. The project analyzes digital payment transactions from 2023–2025 to understand transaction performance, customers, payment methods, merchants, fees, refunds, risk and fraud.

## 🛠️ Tools & Technologies

- Python
- Pandas
- PostgreSQL
- SQL
- Power BI
- DAX

## 📂 Dataset

The project contains 5 main tables:

- Customers
- Transactions
- Merchants
- Risk & Fraud
- Refunds

The dataset contains approximately 200K digital payment transactions from 2023–2025.

## 🔍 Key Insights

- Approximately 200K transactions were analyzed.
- Total transaction value was approximately ₹238.34 million.
- 2024 showed stronger transaction performance compared with 2025.
- Successful transactions were much higher than failed and declined transactions.
- UPI had the highest transaction activity and transaction value.
- Mass customer segment generated the highest transaction activity/value.
- Mobile App was the highest transaction channel.
- Travel was the highest transaction-value merchant category.
- Overall fraud rate was approximately 1.33%.

## 💡 Business Recommendations

- Reduce failed and declined transactions.
- Improve payment channel reliability.
- Monitor fraud and high-risk transactions.
- Improve customer transaction experience.
- Analyze areas where transaction value is declining.
- Monitor refunds and identify major refund areas.
